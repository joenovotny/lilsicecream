The Formspree account email is verified. Form endpoint: https://formspree.io/f/xqpqbgne. Its free plan allows 50 total submissions per month across these forms. Delivery still requires a successful test. Email-update opt-ins are manual requests, not an automated newsletter system. Default provider spam checking remains enabled, with an additional honeypot. The website privacy policy describes this processing. Direct-email alternatives remain available.

Keep GoDaddy domain registration and the separate $6.99 Microsoft 365 email subscription. Preserve all email DNS records. Cancel only the Website + Marketing subscription after HTTPS and actual form delivery have been verified.
